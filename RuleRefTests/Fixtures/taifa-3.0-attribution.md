# Taifa 3.0 rulebook: attribution

`taifa-3.0.pdf` is the Spanish rulebook of the board game Taifa, used unmodified as a test fixture.

- Title: Taifa. Intriga y guerra en la Hispania medieval (rulebook, Spanish, 16 pages).
- Designers: Víctor Catalá, Alex Folch, Ignacio Torres, Jesús Peralta.
- Graphic design: Jesús Peralta.
- Inspired by "Taifa: El juego de la Reconquista" and developed by its same creators (rulebook credits).
- Source: https://printandplay.games/ (as printed in the credits on page 16).
- License: Creative Commons BY-NC-SA, shown as a badge on page 16. The rulebook does not state a license version.
- Version 3.0: taken from the original file name, `Reglas-Taifa-30.pdf`. The rulebook text does not state a version number.
- SHA-256: `1f7c4ae3304b4bd90339825fdf6e756eec20377af575e1dd35ded28bdc4f67bd`

## Use in RuleRef

- Only in the `RuleRefTests` target, for non-commercial testing and evaluation of import and search. Never bundled in the app.
- The file is unmodified; only its name changed.
- Its FAQ is a source of hard questions for evaluations, never ground truth.
